# Chess Mastery

Aplicativo nativo para macOS (**Tauri v2 + React 19 + TypeScript + Tailwind CSS v4**) para estudo interativo de livros clássicos de xadrez com conversão em tempo real entre **Notação Descritiva Clássica (`P4R`, `C3BR`, `B4B`)** e **Notação Algébrica (`e4`, `Cf3`, `Bc4` / `♘f3`)**, traduções em Português pré-instaladas, **Modo Adivinhe o Lance (Spoiler-Free)** e motor de análise local otimizado para Apple Silicon (M1/M2/M3/M4, 8GB+ RAM).

---

## ⬇️ Download e Instalação

Você pode baixar a versão mais recente diretamente do GitHub Releases:

- **Download Direto (.dmg)**: [Chess_Mastery_1.0.0_aarch64.dmg](https://github.com/fabiobertaiolli/chessmastery/releases/download/v1.0.0/Chess_Mastery_1.0.0_aarch64.dmg)
- **Página da Release**: [https://github.com/fabiobertaiolli/chessmastery/releases/tag/v1.0.0](https://github.com/fabiobertaiolli/chessmastery/releases/tag/v1.0.0)

### Como Instalar no Mac:
1. Baixe o arquivo `Chess_Mastery_1.0.0_aarch64.dmg` pelo link acima.
2. Dê dois cliques no arquivo `.dmg` para abrir.
3. Arraste o ícone do **Chess Mastery** para a pasta **Aplicativos** (`Applications`).
4. Abra o Chess Mastery pelo Launchpad ou Spotlight.

## ⌨️ Atalhos de Teclado
- `→` / `←`: Avançar / Retroceder lance da partida
- `Home` / `End`: Ir para o início / final da partida
- `X` ou `F`: Girar o tabuleiro (perspectiva das Brancas / Pretas)
- `Botão Direito no Tabuleiro`: Desenhar setas táticas e destacar casas
