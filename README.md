# Chess Mastery

Aplicativo nativo para macOS (**Tauri v2 + React 19 + TypeScript + Tailwind CSS v4**) para estudo interativo de livros clássicos de xadrez com conversão em tempo real entre **Notação Descritiva Clássica (`P4R`, `C3BR`, `B4B`)** e **Notação Algébrica (`e4`, `Cf3`, `Bc4` / `♘f3`)**, traduções em Português pré-instaladas, **Modo Adivinhe o Lance (Spoiler-Free)** e motor de análise local otimizado para Apple Silicon (M2 8GB RAM).

## Livros Clássicos Pré-Instalados
1. **Xadrez Básico** — Orfeu Gilberto D'Agostini (Português · Descritiva ↔ Algébrica)
2. **Meu Sistema (Mi Sistema)** — Aron Nimzowitsch (Traduzido ES → PT · Bilíngue)
3. **Vida e Partidas de Mikhail Tal** — Mikhail Tal (Traduzido EN → PT · Bilíngue)
4. **Meus Grandes Predecessores, Vol. 4: Bobby Fischer** — Garry Kasparov (Traduzido EN → PT · Bilíngue)

## Atalhos de Teclado
- `→` / `←`: Avançar / Retroceder lance da partida
- `Home` / `End`: Ir para o início / final da partida
- `X` ou `F`: Girar o tabuleiro (perspectiva das Brancas / Pretas)
- `Botão Direito no Tabuleiro`: Desenhar setas táticas e destacar casas
